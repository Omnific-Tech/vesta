## Failures to enumerate before product code

- Compiled manager accidentally depends on external Node/npm/Bun or build checkout.
- Native PTY addon/helper fails after relocation or execution permission is absent.
- Ownership conflicts or missing explicit providers cause partial install writes.
- Upgrade loses warm/timing preferences, unrelated shell/plugin state or globals.
- Update picks draft/prerelease/wrong-platform/version-drift or corrupt assets.
- Authentication/download/verification failure activates or executes bad candidate.
- Integration refresh fails after switch; prior runtime/config becomes unusable.
- Concurrent updates corrupt ownership/state; edited managed block is overwritten.
- Old running sessions lose files or processes due to update/uninstall cleanup.
- Fixed version paths trap already-sourced shells on obsolete launchers.
- Private auth leaks credentials into args/logs/artifacts or source.
- Package/plugin/catalog/tag disagree, fixture build is published or license omitted.
- Runtime native model/permissions/markers/threshold/race/cleanup regress.
