# Vesta

Keep coding sessions warm.

Private project exploring prompt-cache continuity for coding harnesses. A local
experimental TypeScript watcher supports Claude's in-process mod and Codex's
explicitly owned app-server with the native terminal UI. Warming is opt-in; real
cache retention and usage savings remain unproven.

See [local setup, launch, stop and verification](experiments/README.md#local-experimental-watcher).

Engineering uses Telos. Read [AGENTS.md](AGENTS.md) and the
[consumer harness guide](harness/README.md) before starting work.
